## Recognise it

- "**K** largest / smallest / most frequent / closest" → size-K heap (or quickselect).
- Repeatedly take the **next earliest / cheapest** item while adding new ones → priority queue (scheduling, Dijkstra).
- Merge **sorted** streams → heap of heads.
- Median or percentile of a **stream** → two heaps.

<Callout type="analogy">
A hospital emergency room: patients don't leave in arrival order but by urgency. The triage desk always knows who is most urgent, and adding a patient doesn't require re-sorting everyone — just placing them correctly among a few comparisons.
</Callout>

## How a binary heap works

<Walkthrough id="heap-ops" />

A heap is a complete binary tree stored in an array: children of index `i` are `2i + 1` and `2i + 2`, the parent is `(i − 1) / 2`. The **heap property** (each parent ≤ its children for a min-heap) puts the minimum at index 0. Push = append and **sift up**; pop = move the last element to the root and **sift down**. Both touch one root-to-leaf path: O(log n).

| Approach for top-K | Time | Space | Notes |
|---|---|---|---|
| Sort everything | O(n log n) | O(n) | simplest |
| Size-K heap | O(n log K) | O(K) | streams, K ≪ n |
| Quickselect | O(n) average, O(n²) worst | O(1) | in place, unordered result |
| Bucket sort (frequencies) | O(n) | O(n) | when counts are bounded by n |

<Pitfalls>

- **Max-heap of everything for top-K largest** — O(n log n); a size-K min-heap is cheaper.
- **Comparators that overflow** (`a - b` with large ints) — use `Integer.compare`.
- **Python max-heaps** — push negated values (or tuples with negated keys).
- **Ties with uncomparable payloads** in Python tuples — add a counter as a tiebreaker.
- **Assuming iteration order** of a `PriorityQueue` is sorted — only `poll` returns elements in order.

</Pitfalls>

<KeyTakeaways>

- Heaps keep the best element at the top with O(log n) updates.
- Size-K min-heap for K largest; heap of heads for K-way merges; two heaps for medians.
- Know your language's default (min-heap) and how to flip it.

</KeyTakeaways>

## Recognise it

- The input is **sorted** (or sorted then rotated) and you need a position, first/last occurrence, or insertion point.
- "Find the **minimum** X such that something is possible" or "maximum X such that…" — and feasibility is monotone in X.
- Constraints with huge ranges (10⁹) but cheap checks → binary search over the value range.

<Callout type="analogy">
Guessing a number between 1 and 1,000 with "higher/lower" hints. Always guess the middle: at most 10 guesses, because each guess throws away half of what's left.
</Callout>

## The one template to remember

Think of the search as finding the **first index where a predicate is true** (`nums[i] >= target`, "capacity is enough"). Maintain the invariant that the answer lies in `[lo, hi]`.

<CodeTabs id="dsa-binary-search-template" title="First true / lower bound — the boundary template" />

- `predicate(mid)` true → the answer is `mid` or to its left → `hi = mid`.
- false → the answer is to the right → `lo = mid + 1`.
- Loop ends when `lo == hi`: that's the first true (or `n` if none).
- Last occurrence = (first index with `nums[i] > target`) − 1.

## Worked problems

### Search in a rotated sorted array

`[4,5,6,7,0,1,2]`: at any `mid`, one side is sorted. If the target lies within the sorted side's range, search there; otherwise search the other side.

<Pitfalls>

- **Infinite loops** from `lo = mid` with `mid` rounded down — use the first-true template, or round up when moving `lo`.
- **Mixing conventions** (`hi = n` vs `n − 1`, `<` vs `<=`) — pick one template and keep its invariant.
- **Overflow** in `(lo + hi) / 2` with large ints.
- **Non-monotone predicates** — binary search silently gives wrong answers.
- **Wrong bounds for answer search** — the lower bound must be feasible-or-not, and the upper bound must be feasible.

</Pitfalls>

<KeyTakeaways>

- Binary search finds the boundary of a monotone predicate in O(log n).
- One invariant-based template handles first/last occurrence and insertion points.
- Rotated arrays: one half is always sorted.
- Search the answer space when feasibility is monotone.

</KeyTakeaways>

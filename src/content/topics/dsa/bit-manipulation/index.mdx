## Recognise it

- Pairs that cancel, missing/duplicate numbers in a range → XOR.
- Small sets (n ≤ 20) of chosen items → bitmask state (subset enumeration, bitmask DP).
- Flags packed into one integer (permissions, feature sets).
- Powers of two, counting set bits, reversing bits.

<Callout type="analogy">
A row of light switches: each switch is one bit. AND with a mask reads the switches you care about, OR turns some on, AND-NOT turns them off, and XOR flips them — flipping twice returns to where you started, which is why XOR cancels pairs.
</Callout>

## Operators and tricks

| Operation | Expression | Example (x = 12 = 1100₂) |
|---|---|---|
| test bit i | `(x >> i) & 1` | bit 2 → 1 |
| set bit i | `x \| (1 << i)` | set bit 0 → 1101₂ = 13 |
| clear bit i | `x & ~(1 << i)` | clear bit 3 → 0100₂ = 4 |
| toggle bit i | `x ^ (1 << i)` | toggle bit 1 → 1110₂ = 14 |
| clear lowest set bit | `x & (x − 1)` | 1000₂ = 8 |
| isolate lowest set bit | `x & −x` | 0100₂ = 4 |
| power of two? | `x > 0 && (x & (x − 1)) == 0` | 12 → no |

Negative numbers use **two's complement**: `−x = ~x + 1`, so the sign bit is the highest bit.

## Bitmasks as sets

<CodeTabs id="dsa-bitmask-subsets" title="Enumerate all subsets with masks, and iterate submasks" />

With n ≤ ~20, a mask can represent "which items are used so far" in DP — for example the travelling-salesman DP `dp[mask][last]` in O(2ⁿ · n²).

<Pitfalls>

- **Operator precedence**: `x & 1 == 0` parses as `x & (1 == 0)` in Java/JS — parenthesise.
- **Signed right shift** on negative numbers fills with ones; use `>>>` for logical shifts.
- **Overflow**: `1 << 31` is negative in 32-bit ints; use `1L << i` for 64 bits.
- **JavaScript numbers** are converted to 32-bit for bitwise ops; use `BigInt` beyond that.
- **Over-cleverness** — prefer readable code unless the bit trick is the point.

</Pitfalls>

<KeyTakeaways>

- Test/set/clear/toggle with shifted masks; `x & (x − 1)` drops the lowest set bit.
- XOR cancels pairs — finds unique or missing values in O(n), O(1) space.
- Bitmasks represent small sets and enumerate subsets in 2ⁿ.

</KeyTakeaways>
